검증: 15개 회차의 로딩과 쪽수, 132개 체험의 처음 화면을 밝은 테마와 어두운 테마에서 확인했다. 체험 내용이 16:9 슬라이드를 벗어나거나 잘리는 곳이 없는지 자동 점검했고, 회차마다 끝까지 진행한 화면도 확인했다. 3-1, 4-1, 6-2의 전체 인쇄 문서가 쪽수대로 1280 × 720으로 만들어지는 것과 영상 26개가 모두 삽입을 허용하는 것을 확인했다. 실제 터치 기기와 종이 인쇄는 확인하지 않았다.

## 만드는 방법

`scripts/sync_microdegree1.py`가 PowerPoint로 교안의 작업용 사본을 열어 각 슬라이드를 2000 × 1125 WebP로 내보내고 `<회차>.json`을 만든다. 모든 교안은 16:9이며 뷰어도 16:9를 유지한다.

- 강사 이름과 학과명은 작업용 사본에서 지운 뒤 내보낸다. 표지의 이름과 소속, 시간표의 담당 강사 표기가 해당한다. 내보낸 뒤 남은 이름이 있으면 스크립트가 멈춘다.
- 연수 날짜와 오전, 오후 표기도 작업용 사본에서 지운다. 표지의 `10월 10일(토) 오전`, 시간표의 날짜와 `오전`, `오후`, `Part 1 (6주차 오전)` 같은 표기가 해당한다. 5-1의 원본 2쪽 `오전 Part 1`, `오후 Part 2`는 `Part 1`, `Part 2`로, 39쪽과 44쪽의 `오후 준비`, `오후 실습`은 `Part 2 준비`, `Part 2 실습`으로 바꾸었다(`FIXES`). 법 시행일처럼 내용에 속하는 날짜는 그대로 둔다.
- 5-2의 원본 32쪽 실습 자료 주소 `숏.한국/전인성/5주차실습`은 강사 이름이 들어 있지만 자료를 받는 주소이므로 그대로 둔다(`ALLOWED`).
- 영상 슬라이드의 `재생 시간 ○분 ○초` 줄은 지운다.
- 강사를 소개하는 슬라이드는 게시하지 않는다. 1-1의 원본 5쪽(교과목별 주강사)과 1-2의 원본 3~8쪽(강사 소개)이다.
- 발표자 노트는 게시하지 않는다.
- 구분 슬라이드의 제목이 파란 영역을 넘어 흰 곡선 위에서 보이지 않던 두 곳은 작업용 사본에서 줄만 바꾸었다. 4-2의 원본 4쪽과 8-1의 원본 4쪽이며 스크립트의 `FIXES`에 있다. 문구는 그대로다.
- 유튜브 주소가 있는 슬라이드는 그림 자리에 영상을 직접 넣는다(`embeds`). 삽입을 허용하지 않는 영상은 그림을 누르면 유튜브로 이동한다. 삽입 가능 여부는 `videos.json`에 기록한다.
- 슬라이드의 하이퍼링크는 원래 위치에서 바로 열린다(`linkAreas`). 관련 링크 버튼에도 같은 주소가 모인다(`links`).

## 체험 슬라이드

`labs/<회차>.json`의 항목이 `after`로 지정한 원본 슬라이드 바로 뒤에 들어간다. 화면은 `js/microdegree1-labs.js`(카드 분류, 순서 맞히기, 퀴즈, 짝짓기, 선택과 이유, 점검표의 공용 유형)와 `js/microdegree1-labs-<회차>.js`(회차별 내용과 시뮬레이션)가 그린다. 체험 슬라이드도 16:9이며 인쇄할 때 처음 상태로 한 장씩 들어간다.

체험의 문장과 수치는 앞 슬라이드의 내용을 따른다. 시뮬레이션의 예시 데이터와 예시 답은 체험을 위해 만든 것이며 화면의 안내 문장에 그렇게 적었다. 체험은 브라우저 안에서만 동작하고 입력한 내용을 서버로 보내지 않는다. 선택과 이유는 같은 탭에서 뒤 슬라이드가 다시 보여 줄 수 있도록 `sessionStorage`에만 둔다.

체험만 고친 뒤에는 PowerPoint 없이 다음 명령으로 반영한다.

```text
python scripts/sync_microdegree1.py --pages-only
```

뷰어는 `js/computer-education2.js`를 함께 쓴다. `main` 요소의 `data-course`, `data-course-title`, `data-version`으로 과목을 구분한다.

## 글자 선택과 그림 확대

2026-10-13에 슬라이드 이미지 위에 투명한 글자 줄과 그림 영역을 겹쳤다. 본문을 끌어서 선택하고 복사할 수 있고, 그림을 누르면 크게 보인다. 방식과 제외 기준은 `data/lectures/computer-education2/README.md`의 같은 날짜 항목과 같다.

```text
python scripts/sync_slide_layers.py --course microdegree1 --source-dir <PPTX 폴더> --work-dir <임시 폴더>
```

- `sync_microdegree1.py`와 같은 순서로 작업용 사본에서 강사 이름, 날짜, 재생 시간을 지우고 `FIXES`를 적용한 뒤 위치를 읽는다. 게시된 `text`에 없는 줄은 넣지 않으므로 지운 문구는 글자 줄로도 돌아오지 않는다.
- 639장 모두 게시된 이미지와 일치했고, 글자 줄 7,163개와 그림 92개가 들어갔다. 영상이 들어가는 그림과 링크가 걸린 그림은 확대 대상이 아니다.
- `sync_microdegree1.py`로 교안을 다시 내보내면 `lines`와 `pictures`가 사라지므로 이 스크립트를 이어서 실행한다. `--pages-only`는 두 항목을 그대로 둔다.

## 2026-11-07 5주차 교안 교체

5주차 두 교안이 새로 바뀌어 다시 내보냈다. 5-1은 `규칙 기반 전문가 시스템`(원본 44쪽), 5-2는 `생성형 AI 활용`(원본 43쪽)이다.

- 도구 선택, 다음 토큰, 요청문, RAG 내용이 5-2로 옮겨 가서 해당 체험(`nextToken`, `toolTypeSort`, `ageCheck`, `promptBuild`, `fixQuiz`, `ragSteps`, `basisCompare`)도 5-2로 옮겼다. 새 슬라이드의 문장에 맞추어 요청문 예시, 기록지 작성 예시, 근거 표시 방식의 이름을 고쳤다.
- 해당 슬라이드가 빠진 체험 네 개(`contextBudget`, `scanErrors`, `collabQuiz`, `uploadSort`)는 내렸다.
- 5-1에는 체험 열 개를 새로 만들었다. 기호주의와 연결주의 분류, 강 건너기 퍼즐과 컴퓨터 탐색, 조합 폭발 계산, 기호주의 AI 흐름 순서, 구성 요소 짝짓기, 정방향 추론 실행, 역방향 추론과 `왜 묻나요`, 추론 방식 고르기, 규칙표의 문제 찾기, 규칙 기반 AI와 생성형 AI 분류다. 동물 판별 규칙은 슬라이드의 지식 베이스 그대로이고 학교 업무 상황은 체험을 위해 만든 예시다.
- 두 회차의 `data-version`과 체험 스크립트 버전을 `SESSION_VERSIONS`로 올려 이전 자료와 새 이미지가 섞여 보이지 않게 했다.
- 페이지를 만드는 틀을 지금 게시된 페이지(주 메뉴의 강의자료, 관련 실습 바로가기, 자산 버전)에 맞추었다.
- 검증: 두 회차의 체험 23개를 Edge에서 열어 16:9 화면을 벗어나는 요소와 콘솔 오류가 없는지 확인했다. 강 건너기 7번 풀이, 정방향 추론의 치타 결론과 사실이 빠진 경우와 규칙 충돌, 역방향 추론의 질문 수와 설명 기능을 직접 실행했다. 87장 모두 글자 줄 924개와 그림 17개가 들어갔다. 실제 터치 기기와 인쇄는 확인하지 않았다.
