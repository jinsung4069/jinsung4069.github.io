# 컴퓨터과교육2 HTML 강의자료

사용자가 제공한 컴퓨터과교육2 PPTX 10개를 바탕으로 구성했다. 원본 파일은 수정하지 않았다.

| 번호 | 강의 | 슬라이드 수 |
| --- | --- | --- |
| 2 | 컴퓨팅 시스템 | 41 |
| 3 | 데이터의 이해와 표현방법 | 37 |
| 4 | 데이터 구조와 분석 | 38 |
| 5 | 컴퓨팅 사고 기반의 문제 해결 | 64 |
| 6 | 알고리즘의 구조와 종류 | 38 |
| 7 | 프로그래밍 언어의 이해 및 프로그래밍 교육의 실제 | 30 |
| 8 | 인공지능의 이해, 역사 | 77 |
| 9 | 인공지능의 이해 | 28 |
| 10 | 디지털 윤리와 저작권 | 58 |
| 11 | 피지컬 컴퓨팅 | 42 |

원본의 `10 인공지능의 이해`는 사용자 지정에 따라 9번으로 배치했다. 원본 453장에 개념별 체험 슬라이드 10장을 추가해 전체 463장이다.

슬라이드는 PowerPoint에서 글꼴을 적용해 내보낸 2000 × 1125 WebP 이미지다. 원래 그림과 표의 배치를 보존하고 별도로 추출한 HTML 본문으로 목차 검색을 제공한다. 별도의 본문 보기 기능은 제공하지 않는다. 그림 안에 포함된 글자는 원본 그림을 유지한다. 발표자 노트는 게시하지 않았으며 표지의 수업 학기 표기를 제거했다. 교육과정의 대상 학년, 기출문제 연도와 같은 본문 내용은 보존했다.

제목은 Freesentation 8 ExtraBold, 본문과 인터페이스는 Freesentation 6 SemiBold를 사용한다. 웹폰트와 OFL 라이선스는 `fonts/freesentation`에 있다.

삽입 동영상 12개는 전체 재생 길이를 유지해 H.264/AAC MP4로 변환했다. 각 JSON의 `videoFrames`가 원본 슬라이드의 동영상 위치를 보존하며, 그 위치에서 바로 재생한다. `links`는 관련 주소를 연결한다. 체험은 관련 개념 바로 뒤에 별도 슬라이드로 배치했다. `computer-education2-labs.js`의 체험은 강의 개념을 위한 별도의 브라우저 모형이며 실제 기기와 연결하지 않는다.

검증: 453개 이미지와 내부 링크, 12개 동영상의 메타데이터와 변환 전후 길이, 키보드 이동, 페이지 입력, 목차 검색, 전체 화면, 주요 실습 계산, 320px 및 390px 모바일 화면을 확인했다. 브라우저에서 제목과 본문의 실제 웹폰트도 확인했다.

슬라이드 조작은 호버 또는 키보드 포커스 시 나타나는 원형 글래스모피즘 버튼으로 제공한다. 터치에서는 탭 시 잠시 표시한다. 아이콘은 Figma Community에도 배포되는 Lucide이며, 원본 SVG와 라이선스는 `images/icons/lucide`에 있다. 테마 버튼은 메인 페이지의 해와 달 SVG를 사용한다.
