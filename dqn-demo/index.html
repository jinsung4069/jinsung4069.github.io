Q 테이블 기반 강화학습 실습

Tabular Q-Learning Lab

Q 테이블로 학습하기

각 격자 위치와 행동의 가치를 표에 저장하는 Q 학습입니다. 에이전트는 목표에 도달하면 10, 이동할 때는 -0.1의 보상을 받으며 Q 값을 갱신합니다.

  • ε-greedy 정책으로 탐험과 활용을 선택합니다.
  • 탐험률은 에피소드마다 감소하며 최소 0.05를 유지합니다.
  • 한 에피소드는 목표 도달 또는 300회 이동으로 끝납니다.

DQN과의 비교: DQN은 신경망으로 Q 값을 근사하고 경험 재생과 타겟 네트워크를 사용합니다. 이 실습은 표를 직접 갱신하며 이 세 기능을 구현하지 않습니다.

Learning with a Q Table

Tabular Q-learning stores the value of each position and action. Reaching the goal earns 10; each move costs 0.1. These rewards update the Q table.

  • An epsilon-greedy policy balances exploration and exploitation.
  • Epsilon decays each episode to a minimum of 0.05.
  • An episode ends at the goal or after 300 moves.

Comparison with DQN: DQN approximates Q values with a neural network and uses experience replay and a target network. This lab directly updates a table and implements none of those three features.

이 실습의 Q 학습 단계

  1. 환경 관찰: 현재 상태 s를 관찰합니다
  2. 행동 선택: ε-greedy 정책으로 행동 a를 선택합니다
  3. 행동 실행: 환경에서 행동을 실행하여 보상 r과 다음 상태 s'를 얻습니다
  4. 표 갱신: Q(s,a) ← Q(s,a) + α[r + γ max Q(s′,a′) − Q(s,a)]. 종료 상태에서는 다음 상태의 가치를 0으로 둡니다.
  5. 반복: 목표 도달 또는 300회 이동 후 다음 에피소드를 시작합니다.

Q-Learning Steps in This Lab

  1. Observe Environment: Observe the current state s.
  2. Choose Action: Choose action a using the ε-greedy policy.
  3. Execute Action: Execute the action in the environment to get reward r and next state s'.
  4. Update the table: Q(s,a) ← Q(s,a) + α[r + γ max Q(s′,a′) − Q(s,a)]. The next-state value is zero at the goal.
  5. Repeat: Begin another episode after reaching the goal or taking 300 steps.
