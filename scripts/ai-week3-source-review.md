## 제작 기준

사용자의 현재 요청에 따라 3주차 제목을 ‘인공지능의 이해와 원리’로 구성했다. 오리엔테이션의 이전 주차 배치는 현재 요청으로 대체하고, 강의자료의 AI알고리즘 목록에 2주차 다음으로 연결했다. 이전 강의 페이지와 원본 PPTX/PDF는 수정하지 않았다.

개념, 역사, 규칙과 추론, 기계학습, 신경망과 생성, 문제 해결 과정의 순서로 55장을 구성했다. 설명 다음에 계산 또는 판단 체험을 배치하고, 가상 자료는 가상이라고 표시했다. 현재 웹 강의의 표지, 구분 슬라이드, 파란 제목 띠, Freesentation 제목 800과 본문 600 서식을 사용했다. 학년, 학기, 발표자 참고, 재사용한 과거 강의의 출처 표기는 넣지 않았다. 원 교재 그림과 외부 원문 자료의 출처는 유지했다.

## 현재 과목 자료 추가 확인 및 원본 도식 재사용

AI알고리즘 오리엔테이션 3~15장에서 목표, 교재와 실습 환경을 확인했다. 과목 폴더의 ‘1장_기계학습과 신경망의 이해.pptx’ 1~18장과 ‘2장_머신러닝 기반 문제 해결 과정_오렌지와 구글 코랩의 활용.pptx’의 목차도 확인했다.

‘1장_기계학습과 신경망의 이해.pptx’ 5, 7, 8, 9, 12, 14, 15장을 렌더링하고 그림의 적합성을 확인했다. 7장의 `ppt/media/image18.png`와 8장의 `ppt/media/image19.png`를 원본 이미지 그대로 추출해 새 강의 27, 28장에 배치했다. 슬라이드 전체를 이미지로 만든 것이 아니라 현재 템플릿 안에 원본 설명 도식을 옮겼다. 교재 출처는 김현철 외, 『오렌지3 with 파이썬』, 생능북스로 표시했다.

## 외부 대조 자료

- McCarthy, What is Artificial Intelligence: https://www-formal.stanford.edu/jmc/whatisai/whatisai.html
- Dartmouth 연구 제안서: https://www-formal.stanford.edu/jmc/history/dartmouth/dartmouth.html

- DeepMind AlphaGo: https://deepmind.google/research/alphago/
- Vaswani 외, Attention Is All You Need: https://arxiv.org/abs/1706.03762
- Google 경사하강법: https://developers.google.com/machine-learning/crash-course/linear-regression/gradient-descent
- scikit-learn 데이터 누수: https://scikit-learn.org/stable/common_pitfalls.html

단일 원인으로 AI 겨울을 설명하거나, 모든 강화학습을 시뮬레이션으로 한정하거나, 신경망 학습을 모두 강화학습이라고 부르는 설명은 사용하지 않았다. 규칙 기반 AI도 포함하고, 학습과 추론을 구분했다. 보상 체험은 학습 실행이 아니라 경로 점수 비교임을 표시했다. 언어 생성 체험은 가상의 후보 확률표이며 실제 언어 모델이라고 표시하지 않았다.

## 검증

`tests/ai-week3.browser.cjs`로 55장 데스크톱 및 모바일 폭, 13개 활동, A/D와 방향키, F 전체화면, 입력 중 단축키 충돌 방지, 검색, 다운로드, 터치 넘김, 인쇄 준비를 확인한다. 실제 생성 PDF는 55쪽, A4 가로 크기이며 표지, 본문, 도식, 주요 체험의 인쇄 화면을 확인했다. 코랩 노트북의 모든 코드 셀을 실행했으며 훈련으로 선택한 경계는 5.5, 고정된 가상 테스트 자료 정확도는 1.0이었다. 이 작은 가상 자료의 점수를 실제 모델 성능으로 해석하지 않는다.
