# 마음길 코치 Gemini 연결 서버

이 버전은 만 18세 이상 성인 교육 전문가가 가상 사례로 검토하는 시제품입니다.
실제 학생용 서비스 운영이나 실제 학생의 개인정보와 상담 기록 입력을 허용하지 않습니다.
Google AI Studio에서 발급한 키를 사용하며 모델은 gemini-3.8-flash, 기본 추론은 low입니다.

## 로컬 실행

Node.js 22 이상에서 이 폴더의 server.mjs를 실행합니다.

```powershell
node server.mjs
```

실행 후 다음 두 주소를 엽니다.

- 키 입력 화면: http://127.0.0.1:8787/local-setup
- 검토 페이지: http://127.0.0.1:8787/maeumgil-coach/

키 입력 화면의 비밀번호 입력 칸에 발급받은 키를 직접 붙여 넣습니다.
화면은 서버가 이 컴퓨터의 127.0.0.1에 연결됐을 때만 열립니다.
입력된 키는 모델 접근 권한 확인 후 서버 메모리에만 저장되고 서버가 종료되면 사라집니다.
일반 채팅, config.js, GitHub 파일에 키를 붙여 넣지 마세요.
검토 페이지에서 AI 연결을 누르면 서버에 성인 검토 세션을 만듭니다.

환경변수 GEMINI_API_KEY 또는 GOOGLE_API_KEY가 이미 설정됐다면 그대로 사용할 수 있습니다.
지속 설정이 필요할 때는 .env.example을 참고하여 이 폴더에 .env.local을 직접 만들 수 있습니다.
.env.local은 저장소의 기존 .gitignore로 제외되며 정적 파일 서버에서도 차단됩니다.
별도 패키지 설치는 필요하지 않습니다.

## GitHub Pages와 연결

화면은 /maeumgil-coach/ 하위 페이지에 있습니다.
GitHub Pages는 정적 호스팅이므로 이 Node 서버를 실행하지 않습니다.
공개 환경의 AI 대화에는 별도 HTTPS Node 서버와 성인 전문가용 접근 제어가 필요합니다.

서버 환경변수에 다음을 설정합니다.

- GEMINI_API_KEY
- HOST, 예: 0.0.0.0
- PORT
- EXPERT_ACCESS_CODE, 최소 16자 이상의 무작위 값
- ALLOWED_ORIGINS, 기본값 https://jinsung4069.github.io
- GEMINI_THINKING_LEVEL, low 또는 medium 또는 high

공개 서버는 HTTPS 역방향 프록시 뒤에서 운영하고 성인 전문가에게만 접속 코드를 전달합니다.
접속 코드만으로 충분한 연령 확인과 기관 접근 정책을 구현했다고 간주하지 않습니다.
노출된 접속 코드는 교체하고 운영 환경에 맞는 로그인, 접근 제한, 비용 한도를 적용해야 합니다.
공개 서버에서는 /local-setup 경로가 열리지 않습니다.
화면의 config.js에 서버 주소만 넣거나, AI 연결 창에서 HTTPS 서버 주소를 입력합니다.
브라우저에는 모델 키를 보내지 않으며 공개 코드와 설정에 키를 포함하지 않습니다.
이 작업은 로컬 파일 생성이며 서버 배포나 Git push를 자동으로 수행하지 않습니다.

## 구현한 개선

- 감정 선택, 선택형 후속 응답, 쉬운 표현 수준, 읽어주기
- 점검 6문항의 프로그램 채점, 이전 응답 수정, 중단과 복귀
- 근거 없는 총점 구간 해석 제외
- AI의 작은 목표 제안은 사용자 확인 후 목표 카드에 반영
- 목표 타이머, 시도한 뒤 돌아보기, 더 작게 바꾸기
- 호흡 안내의 시작과 중단, 화면 전환과 백그라운드에서 중단
- 클라이언트와 서버의 보조 위험 표현 검사, 모델의 맥락 판별
- 위험 분기에서 후속 질문과 목표 제안 중단
- 요청 시간 제한, 같은 요청 재시도의 중복 실행 방지, 세션 격리와 만료
- 서버 대화 맥락은 메모리에 임시 보관하고 마지막 활동 후 30분이 지나면 세션을 만료
- 서버는 상담 원문과 키를 로그로 남기지 않음
- 브라우저의 localStorage와 sessionStorage에 대화와 목표를 저장하지 않음
- 성인 검토용 요약 다운로드에는 대화 원문과 문항별 응답을 포함하지 않음

위험 표현 검사는 보조 장치이며 완전한 안전 평가가 아닙니다.
Interactions 요청은 store:false로 보내지만 Google의 데이터 처리 약관을 대체하지 않습니다.
음성 입력은 브라우저 음성 서비스에 전달될 수 있어 실행 전에 안내하고,
인식된 문장은 사용자가 확인하고 보내기를 누르기 전까지 대화 서버로 보내지 않습니다.
읽어주기는 브라우저의 음성 합성을 사용하며 Gemini의 음성 생성 기능이 아닙니다.

## 확인

```powershell
node --test test.mjs
```

검사는 점검의 경계값, 잘못된 응답, 위험 분기, 응답 형식, Interactions 요청 형식,
오류 처리를 모의 응답으로 검증합니다. 실제 모델 응답의 품질이나 임상적 효과 검증이 아닙니다.
