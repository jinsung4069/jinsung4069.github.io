# 우리반 AI (Stitch AI) PoC 통합 프로젝트 구현 워크스루

제공해주신 화면정의서(PPTX)와 사전기획 프로토타입(ZIP)을 바탕으로 분리된 9개의 화면을 하나로 통합하고, 이를 유기적으로 체험할 수 있는 포털 시스템의 구축을 완료했습니다.

---

## 1. 주요 구현 내용 요약

### 1) 프리미엄 메인 포털 신규 구축
- **위치:** [/stitch_ai_poc/index.html](file:///c:/Users/jinsu/Desktop/Programming/jinsung4069.github.io/stitch_ai_poc/index.html)
- **디자인 & 인터랙션:**
  - `DESIGN.md` 및 화면정의서의 브랜딩 철학(오렌지/차콜 테마, Plus Jakarta Sans & Inter 서체)을 충실히 반영.
  - **인터랙티브 로드맵 (화면 Flow):** 교사용 및 학생용 여정이 타임라인 노드로 시각화되어 있어 사용자가 현재 위치를 확인하고 원하는 시연 위치로 언제든지 바로 건너뛸 수 있음.
  - **화면 카드 그리드:** 9개의 모든 화면을 슬라이드 번호 및 역할별 태그와 함께 카드 형태로 정렬. 각 카드는 제공된 `screen.png`를 썸네일로 렌더링하고 호버 시 부드러운 스케일업 및 하이라이트 효과 적용.

### 2) 유기적 화면 연동 (Interactive Scenario)
기존에 끊어져 있던 버튼과 링크들을 시나리오 동선에 맞게 상대 경로로 연결하여, 터치 및 클릭만으로 시뮬레이션 전체를 완주할 수 있게 개선했습니다.
- **홈 (`ai_2`):** '무료 시작하기' 클릭 시 바로 **교사 대시보드 (`ai_4`)**로 순간이동하며, 하단 보조 네비게이션 바의 버튼들도 실제 타겟 페이지로 연동됩니다.
- **대시보드 (`ai_4`):** '새 수업 만들기' 또는 '임시저장' 학급 카드를 누르면 **성취기준 튜터 디자이너 (`ai_1`)**로 연결됩니다. '진행중' 학급 카드를 누르면 **실시간 Live 모니터링 (`ai_live`)**으로 연결되고, '종료' 학급 카드를 누르면 **최종 증빙 리포트 (`ai_6`)**로 직행하여 각 카드의 교육학적 상태에 따른 하이파이(High-Fidelity) 움직임을 보여줍니다.
- **디자이너 & 고급 설정 (`ai_1`, `ai_3`):** '학생 화면 미리보기'를 클릭하면 에뮬레이터 프레임인 **학생 모드 미리보기 (`ai_8`)**가 띄워지고, '바로 배포' 시 **Live 모니터링 (`ai_live`)**이 시작됩니다.
- **학생 학습 공간 (`ai_5`):** 학생이 AI 발문에 따른 서술 작성을 마치고 '제출하기'를 누르면, 백엔드 분석 및 전송 성공을 알리는 **글래스모피즘 팝업 모달**이 출력되며, 클릭 시 즉시 **과정 증빙 리포트 (`ai_6`)**로 이동하는 매끄러운 궤적을 그립니다.
- **리포트 & 동의 패널 (`ai_6`, `ai_7`):** 리포트 하단의 '지적 영수증(IR) 보기'를 누르면 개인정보 및 보안을 점검하는 **관리자 패널 (`ai_7`)**로 가며, 최종적으로 '시나리오 홈으로 돌아가기' 클릭 시 **PoC 메인 포털 (`index.html`)**로 안전하게 복귀합니다.

### 3) 공통 플로팅 PoC 헬퍼 내비게이터 주입
- 모든 화면 우측 하단에 `psychology` 튜터링 메인 아이콘 형태의 플로팅 버튼을 추가했습니다.

## 2. 시연 경로 가이드

시현 또는 테스트 시 다음의 두 가지 시나리오 시뮬레이션을 타실 수 있습니다.

### 시나리오 A: 교사용 시나리오 (전체 관류 흐름)
1. **[PoC 메인 포털](file:///c:/Users/jinsu/Desktop/Programming/jinsung4069.github.io/stitch_ai_poc/index.html)** 접속 -> **교사 시나리오 전체 플레이** 클릭
2. **서비스 랜딩 홈 (`ai_2`)** 진입 -> **교사 대시보드로 이동** 클릭
3. **교사 대시보드 (`ai_4`)** 진입 -> **새 수업 만들기** 클릭
4. **튜터 디자이너 (`ai_1`)** 진입 -> 대상 및 기준 설정 검토 후 **고급 설정 단계로** 클릭
5. **정밀 설정 (`ai_3`)** 진입 -> 넛지 및 루브릭 셋업 검토 후 **바로 배포** 클릭
6. **Live 지도 모니터링 (`ai_live`)** 진입 -> 최예린 학생 주의 신호 및 ENA 맵 실시간 분석 검토 후 **리포트로 넘어가기** 클릭
7. **평가 설명 리포트 (`ai_6`)** 진입 -> HCR 지표 및 ENA 궤적 검토 후 하단 **학습 과정 인증서 (지적 영수증) 보기** 클릭
8. **개인정보 및 보안 패널 (`ai_7`)** 진입 -> 비식별 암호화 조치 확인 후 **시나리오 홈으로 돌아가기** 클릭하여 포털로 안전하게 귀환.

### 시나리오 B: 학생용 시나리오 (개별 학습 흐름)
1. **[PoC 메인 포털](file:///c:/Users/jinsu/Desktop/Programming/jinsung4069.github.io/stitch_ai_poc/index.html)** 접속 -> 하단 로드맵에서 학생 여정의 **2단계: 학생 학습 공간** 클릭
2. **학생 학습 공간 (`ai_5`)** 진입 -> 튜터와의 대화형 발문 및 ENA 사고 맵 검토 후 상단 **제출하기** 클릭
3. 완성 안내 팝업 출력 -> **과정 증빙 리포트 확인하기** 클릭하여 **평가 설명 리포트 (`ai_6`)**로 넘어가 학생 시점의 피드백 검증.
